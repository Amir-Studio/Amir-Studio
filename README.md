# AmirStudio — Independent Digital Design Studio

A lightweight, static HTML/CSS/JavaScript portfolio and studio website published with GitHub Pages.

## Structure

- `index.html` — main studio experience
- `css/` — modular global, hero, works, studio, journal, contact, and case-study styles
- `js/` — navigation, scroll/reveal motion, and contact form behavior
- `projects/<project>/index.html` — individual project case studies
- `journal/` — editorial notes
- `assets/amir-studio-logo.png` — original brand logo (kept unchanged)
- `assets/images/` — reserved for optimized local hero, work, and studio imagery
- `assets/video/` — reserved for original, optimized project/hero films

## Principles

- No fabricated client outcomes, project screenshots, or architecture claims.
- Project pages use imagery from the corresponding published projects.
- The hero is a static editorial image with a responsive source and no autoplay video.
- The contact form opens the visitor's email client; it does not claim to submit to a backend.
- Motion respects `prefers-reduced-motion`.
- No build step or package manager is required.
