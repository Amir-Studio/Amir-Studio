پاسخ صفحهٔ ۳۲

عدد هزار، ارزش پول و ارزش مکانی

پرسش ۱ — انتخاب ظرف یا مکان مناسب

برای جا دادن تعداد بسیار زیاد از یک چیز، باید گزینه‌ای را انتخاب کرد که ظرفیت بزرگ‌تری داشته باشد؛ مثلاً برای ۱۰۰۰ ماشین، اتوبان مناسب‌تر از کوچه است و برای ۱۰۰۰ صندلی، دانشگاه از یک کلاس کوچک مناسب‌تر است.

این سؤال برآوردی است؛ پاسخ دقیق بعضی گزینه‌ها به عبارت‌بندی چاپ کتاب بستگی دارد.

پرسش ۲ — تبدیل تومان به ریال

هر تومان برابر ۱۰ ریال است؛ پس برای تبدیل تومان به ریال در ۱۰ ضرب می‌کنیم.

۱۰۰ × ۱۰ = ۱۰۰۰ ریال

پاسخ: ۱۰۰ تومان برابر ۱۰۰۰ ریال است.

پرسش ۳ — جمع و تفریق و تجزیهٔ عددها

۴ هزار + ۳ هزار = ۷۰۰۰
۴ صد + ۲ صد = ۶۰۰
۵ ده + ۴ ده = ۹۰
۲۰۰ + ۸۰۰ = ۱۰۰۰
۵۰۰۰ − ۲۰۰۰ = ۳۰۰۰
۲۰ + ۳۰ = ۵۰
۳۰۰۰ + ۴۰۰۰ = ۷۰۰۰
۱۰۰۰ − ۳۰۰ = ۷۰۰
۴۰۰ + ۶۰۰ = ۱۰۰۰
۸۰۰ − ۳۰۰ = ۵۰۰
۱۰۰۰ − ۵۰۰ = ۵۰۰
۵۰۰ + ۵۰۰ = ۱۰۰۰
۸۰۰۰ + ۷۰ + ۳ = ۸۰۷۳
۳۰۰۰ + ۲۰۰ + ۴۰ + ۱ = ۳۲۴۱

در تجزیهٔ عدد، هر رقم را بر اساس ارزش مکانی‌اش می‌نویسیم؛ مثلاً ۳۲۴۱ یعنی ۳ هزار، ۲ صد، ۴ ده و ۱ یک.
